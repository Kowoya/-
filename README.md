# Система для ефективного виконання серії завдань

Програма мовою C, яка виконує серію завдань і виводить результат кожного з них. Перед виходом вона показує зведену статистику.

## Архітектура

Система складається з двох однопотокових процесів, які створює `fork()`:

- **Інтерфейсна частина (UI)** - батьківський процес. Приймає завдання, консолідує результати і веде статистику.
- **Виконавча частина (Executive)** - дочірній процес. Зберігає словник обробників і виконує їх.

Процеси обмінюються даними через два канали `pipe()`:

- `request_pipe`: UI -> Executive, тільки параметри;
- `response_pipe`: Executive -> UI, тільки результати.

```
Користувач --(серія завдань)--> [UI] --(параметри)--> [Executive]
Користувач <--(результати)----- [UI] <--(результати)-- [Executive]
```

Завдання складається з вхідного значення та переліку обробників. Значення подається на вхід кожному обробнику, а UI консолідує їхні результати функцією (за замовчуванням - добуток).

## Збирання

```
gcc -std=c11 -Wall -Wextra -O2 src/task_system.c -o task_system -lm
```

## Запуск

```
./task_system                            # система сама запитує параметри
./task_system 5:sq,inc 3:fact,dbl        # завдання з командного рядка
./task_system -c sum 2.5:sq,cube         # інша функція консолідації
```

Формат завдання в командному рядку: `значення:обробник1,обробник2`.

Функції консолідації: `prod` (за замовчуванням), `sum`, `min`, `max`, `avg`.

В інтерактивному режимі команда `list` показує словник обробників, а `q` завершує роботу.

## Словник обробників

| Ім'я | Дія | Обмеження |
| --- | --- | --- |
| sq | x^2 | - |
| cube | x^3 | - |
| inc | x + 1 | - |
| dec | x - 1 | - |
| dbl | 2x | - |
| half | x / 2 | - |
| neg | -x | - |
| abs | \|x\| | - |
| sqrt | корінь x | x >= 0 |
| inv | 1 / x | x != 0 |
| ln | ln x | x > 0 |
| fact | x! | ціле від 0 до 170 |
